// Import Tasks as CSV

📄 CSV Format Guide ▼

Columns

ColumnRequired?Notes
title requiredCard title — 200 characters max
description optional5000 characters max
status optionalidea (default), todo, in_progress, in_review, or done
priority optionallowest, low, medium (default), high, or highest
type optionaltask (default), story, subtask, or epic
assignee optionalAn existing member's username (not display name) — case-insensitive. No match on this site → card imports unassigned, not an error
due_date optionalYYYY-MM-DD
parent optionalThe exact title of another row in this file, or an existing card already on the board — makes this row a subtask. No match → card still imports, just without the subtask link
 
title,description,status,priority,type,assignee,due_date,parent
"Design the fall flyer","For the CTF kickoff",todo,high,task,gprisk,2026-11-01,
"Pick the flyer font",,todo,low,subtask,,,"Design the fall flyer"

Only title is required — every other column can be left blank or omitted entirely. Whole file is rejected (nothing is imported) if any row fails validation, so check the error message and re-upload rather than needing to clean up a half-imported board. Max 500 rows, 1MB file size. No per-row assignment emails fire on import — only a manually created or edited card notifies its assignee.
